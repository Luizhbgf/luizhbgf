## Sobre mim

Desenvolvedor com experiência em **aplicações web e mobile** e em **sistemas legados de mainframe**. Combino tecnologias modernas (React, React Native, Node.js) com linguagens consolidadas (COBOL, Natural, Assembly) para entregar soluções sólidas, eficientes e fáceis de manter.

- 💼 Desenvolvimento web, mobile e backend
- 🏛️ Manutenção e evolução de sistemas mainframe
- 📚 Aprendizado contínuo e foco em boas práticas
- 🤝 Aberto a colaborações e novas oportunidades
